## 2026-10-28

### WaveWorks 소리 실험실 첫 구현

- 파형, 배음, 화음, 리듬을 직접 만들고 눈으로 확인하는 네 개의 실험실을 만들었습니다.
- 브라우저의 Web Audio API만 사용해 소리를 실시간으로 합성합니다. 오디오 파일, 서버, 로그인은 사용하지 않습니다.
- 파형과 스펙트럼을 실시간으로 보여 주고, 시각 전용 모드에서는 소리 없이 숫자와 그림만으로 실험할 수 있습니다.
- 다섯 가지 도전을 예측 → 만들기 → 비교 순서로 진행할 수 있습니다. 예측을 맞혀야 실험실이 열리고, 완료 기록과 답안은 이 기기에 저장됩니다.
- 교사용 화면에서 수업 최대 음량, 시각 전용 모드, 동작 줄이기, 도전 선택, 진행 기록 초기화를 설정할 수 있습니다.
- 청력 보호 안내를 처음 실행할 때 보여 주고, 마스터 음량은 기본 18%, 최대 60%로 제한했습니다.
- 컴퓨터 키보드로 피아노를 연주하고, 키보드만으로 모든 조작을 할 수 있게 했습니다.
- 휴대폰, 태블릿, 데스크톱 화면에 맞춘 반응형 배치와 오프라인 설치(PWA)를 적용했습니다.
- 주파수 계산, 화음 간격, 배음, 음량 제한, 스케줄러, 도전 채점에 대한 자동 테스트를 추가했습니다.
